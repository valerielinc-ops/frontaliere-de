CSS Versicherung hat aktuell 48 offene Stellen auf Frontaliere Ticino, verteilt auf 6 Schweizer Kantone. Der Kanton LU hat die meisten Stellen (26), gefolgt von VD (4), SO (3), AG (2), BL (2), SZ (2). Nach Stadt betrachtet haben Luzern (19 Stellen) die meisten offenen Stellen, gefolgt von Root (6), Lausanne (4), Liestal (2), Solothurn (2), Altstätten (1). Das geschätzte Median­gehalt für diese Stellen beträgt CHF 87'750 brutto pro Jahr. In den letzten 28 Tagen wurden 33 neue Stellen veröffentlicht. 33 der 48 aktiven Stellen sind teilzeit. Die veröffentlichten Gehälter für diese Stellen reichen von CHF 49'500 bis CHF 146'000 brutto pro Jahr.
